## Install 1. Download the latest release (or `Code → Download ZIP`) and unzip it. 2. Run **`Setup.cmd`** and allow administrator rights (needed once to put a tiny script loader into the browser folder). 3. Pick a theme, wallpaper, accent color, light/dark mode, corners, animations and features, then choose the browsers. 4. Press **Install** and restart the browser. Prefer the console? `install.cmd` does the same with text prompts. If SmartScreen appears: *More info → Run anyway*. Want a single `.exe` to send to someone? Run **`build-exe.bat`** in the version folder: it packs the installer into `hand_design-Setup-v.exe` using only built-in Windows tools (PowerShell + IExpress). The batch file is not part of the release zips. Use the built-in browser theme **"System theme — auto"** — third-party themes repaint the window frame. ## Uninstall `Setup.cmd` → **Remove theme** (or `uninstall.cmd`). The previous look, the stock PDF viewer and default settings come back after a restart. Your own `userChrome.css` / `userContent.css` rules are kept; backups are saved as `*.bak-floorp-modern`. ## After a browser update A major update may remove the loader from the program folder. If the toolbar buttons or PDF features disappear, run `Setup.cmd` again. ## How it works | Where | What | |---|---| | Browser folder (`C:\Program Files\…`) | `config.js` + `defaults\pref\config-prefs.js` — AutoConfig loader | | Profile `chrome\userChrome.css` | Browser interface (block `FLOORP-MODERN`) | | Profile `chrome\userContent.css` | New tab, settings pages, PDF viewer (blocks `FLOORP-MODERN`, `PDF-TWEAKS`) | | Profile `chrome\pdf-tweaks\` | Window features, PDF actor, Studio, wallpapers, themes for live switching (`themes\`) | | Profile `user.js` | A few prefs (stylesheets, Nova, animations) | The theme is stored in the `floorp.modern.theme` pref; the theme block inside the CSS files sits between `FM-THEME BEGIN/END` markers, so the browser can swap it itself. Studio settings are stored in the `floorp.modern.studio` pref and applied as a live stylesheet — no restart needed. Logs for troubleshooting: `chrome\pdf-tweaks\fm-log.json` and `fm-boot.json`. ## Development CSS is generated by the scripts in `tools/`: ```sh python3 tools/gen_chrome.py files # base chrome + content CSS python3 tools/gen_css.py > files/pdf-viewer-theme.css python3 tools/gen_ios.py src/themes # iOS overlay (source) python3 tools/gen_themes.py src/themes # other theme overlays (source) python3 tools/pack_themes.py # themes for installer + live switching sh tools/build.sh # release zip ``` ## Disclaimer Unofficial community mod, not affiliated with or endorsed by Mozilla or Ablaze (Floorp).
